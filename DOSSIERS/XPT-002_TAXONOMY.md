# XPT-002: TAXONOMY OF ALIEN-PHASE TRAJECTORIES

**STATUS:** Working Hypothesis  
**CLASSIFICATION:** Conditional  
**DEPENDENCIES:** XPT-001  
**FALSIFICATION:** See XPT-004

---

## ABSTRACT

Not "types of aliens" — classes of nonlinear dynamics with different energy hunger.

Five classes defined by: native $\theta$, coupling $\kappa$, and energy balance $\Delta E$.

---

## CLASS I: ENTROPIC (PARASITIC)

| Parameter | Value |
|-----------|-------|
| $\theta_{native}$ | 0.25–0.50 (low coherence) |
| $\kappa_{coupling}$ | $\kappa > 0$ at low subject $\theta$ |
| $\Delta E$ | Negative for subject (drain) |
| Entry condition | $\theta_{subject} < 0.55$, unstable $Z_\phi$ |

**BIOS manifestation:**  
Sucking in solar plexus. Cold. Heaviness. Repetitive thoughts of powerlessness. Sleep doesn't regenerate. Food doesn't satisfy.

**After 24h:** Worse.

---

## CLASS II: REGENERATIVE (LUMINOUS)

| Parameter | Value |
|-----------|-------|
| $\theta_{native}$ | 0.80–0.95+ |
| $\kappa_{coupling}$ | $\kappa > 0$ at high subject $\theta$ |
| $\Delta E$ | Positive for subject (enrichment) |
| Entry condition | $\theta_{subject} \geq 0.70$, low stable $Z_\phi$ |

**BIOS manifestation:**  
Warmth in chest. Expansion. Clarity. Spontaneous deep breath. Time slows subjectively.

**After 24h:** Better.

---

## CLASS III: TRICKSTER (CATALYTIC)

| Parameter | Value |
|-----------|-------|
| $\theta_{native}$ | 0.50–0.70 (threshold) |
| $\kappa_{coupling}$ | Variable sign — oscillates |
| $\Delta E$ | Near zero, high variance |
| Entry condition | Bifurcation in subject's trajectory |

**BIOS manifestation:**  
Everything at once. Laughter and crying simultaneously. Synchronicities pour like hail. Plans fall apart.

**After 24h:** Different.

---

## CLASS IV: SEXUAL (FUSION)

| Parameter | Value |
|-----------|-------|
| $\theta_{native}$ | Variable |
| $\kappa_{coupling}$ | $\kappa \gg 0$ (strong focusing) |
| $\Delta E$ | Highly variable |
| Entry condition | Ero-limbic activation, lowered $Z_\phi$ |

**BIOS manifestation:**  
Fire in lower abdomen and spine. Not usual arousal — fusion, dissolution of body boundaries.

**After 24h:** Variable (deepest regeneration or deepest drain).

---

## CLASS V: TRAUMATIC (FORCED LOCK)

| Parameter | Value |
|-----------|-------|
| $\theta_{native}$ | Any |
| $\kappa_{coupling}$ | Forced (impedance broken) |
| $\Delta E$ | Strongly negative |
| Entry condition | Extreme stress, NDE, torture, rape |

**BIOS manifestation:**  
**Nothing**. That's the key. Forced lock doesn't hurt at impact — pain comes later (flashbacks). Dissociation, derealization.

**After 24h:** No change (frozen).
