# PROTOCOL: 24H DIAGNOSTIC

**STATUS:** Operational  
**CLASSIFICATION:** Monitoring  
**FREQUENCY:** Daily (5 min) + Weekly (30 min)  
**TOOLS:** None (body-based)

---

## ABSTRACT

Quick self-assessment of $\theta$ and lock type.

No equipment. No apps. Just body and attention.

---

## DAILY CHECK (5 minutes)

### Morning (2 min)

**1. Hand on heart (60s)**
- Feel rhythm
- Regular, full = $\theta \uparrow$
- Chaotic, shallow = $\theta \downarrow$
- Note: warm/cold

**2. Breath count (30s)**
- Natural breath, don't control
- Count for 60s
- $\leq 8$: $\theta \geq 0.70$
- $12-16$: $\theta \approx 0.50$
- $\geq 18$: $\theta \leq 0.40$

**3. Body scan (30s)**
- Overall: warm or cold?
- Tension: open or compressed?
- Energy: light or heavy?

**4. Intention (30s)**
- Not goal ("do X")
- Quality ("presence", "clarity", "grounded")
- One word

### Evening (3 min)

**1. Energy balance**
- Net: positive / neutral / negative
- Compared to morning: ↑ / → / ↓

**2. Lock detection (if applicable)**
- Did I experience unusual phenomenon today?
- If yes, classify (use table below)

**3. Sleep preparation**
- Screens off: 1h before bed
- Room: cool, dark
- Intention: "restorative sleep"

## LOCK TYPE CLASSIFICATION (if phenomenon detected)

Use this table immediately after experience:

| Question | Class I | Class II | Class III | Class IV | Class V |
|----------|---------|----------|-----------|----------|---------|
| **Energy during** | Draining | Charging | Chaotic | Intense | None (frozen) |
| **Body temp** | Cold | Warm | Variable | Hot | Numb |
| **Thoughts** | Repetitive, anxious | Clear, quiet | Absurd, jumping | Dissolved | Disconnected |
| **Time sense** | Drags | Slows | Shatters | Vanishes | Cracks |
| **After 1h** | Worse | Better | Different | Variable | No change |
| **Can I stop it?** | No (sticky) | Yes (fluid) | No (chaotic) | Yes (fluid) | No (frozen) |

**If mostly Class I or V:**
- Initiate LOCKDOWN protocol
- Don't wait 24h
- Act immediately

**If Class II:**
- Observe, don't cling
- Let it flow
- Integrate naturally

**If Class III:**
- Surrender to chaos
- Don't control
- Trust process (but keep Human Anchor available)

**If Class IV:**
- Check $\theta$ of both sides
- If both ≥ 0.70: regenerative fusion
- If one low: potential drain
- Aftercare essential

## WEEKLY ASSESSMENT (30 min)

Once per week, deeper check:

### 1. $\theta$ Trend (10 min)

**Graph (mental or paper):**
- Plot daily $\theta$ proxy (breath count or HRV feel)
- 7 days
- Trend: ↑ / → / ↓

**Interpretation:**
- ↑: Protocol working, continue
- →: Stable, but check if plateau (stasis = death)
- ↓: Something wrong, investigate

### 2. Lock Inventory (10 min)

**List all unusual experiences this week:**
- Date/time
- Type (I–V)
- Duration
- After-effect (better/worse/different)

**Pattern detection:**
- Same type repeating?
- Same time of day?
- Same location?
- Same trigger?

**If pattern:**
- Investigate (what's the gradient?)
- Or avoid (if Class I/V)

### 3. Protocol Adherence (10 min)

**XPT-004 protocol check:**
- Heavy work: ≥ 60 min/day? (Y/N)
- Breath practice: 2×/day? (Y/N)
- Forest/soil: ≥ 3h/week? (Y/N)
- Sleep sync: ±1h sunset/sunrise? (Y/N)
- Food: zero ultra-processed? (Y/N)
- Info-hygiene: reduced random input? (Y/N)

**Score:**
- 6/6: Excellent
- 4–5/6: Good, improve weak points
- < 4/6: Protocol failing, reset

## RED FLAGS (immediate action)

If any of these, **don't wait for weekly assessment**:

1. **$\theta < 0.50$ sustained** (≥ 3 days)
   - → Initiate LOCKDOWN

2. **Class I or V lock detected**
   - → Initiate LOCKDOWN immediately

3. **Cannot sleep ≥ 2 nights**
   - → Clinical help

4. **Cannot eat or compulsive eating**
   - → Clinical help

5. **Relations falling apart**
   - → Λ-R protocol

6. **Cannot stop talking about "experiences"**
   - → Info-hygiene lockdown

7. **Cannot close "channel"**
   - → LOCKDOWN + Human Anchor

8. **Feeling "controlled" or "not-self"**
   - → LOCKDOWN immediately

---

## GREEN FLAGS (system healthy)

1. $\theta \geq 0.65$ baseline
2. Sleep restorative
3. Body warm, breath deep
4. Gut calm
5. Relations stable or deepening
6. Can be silent about experiences
7. Can initiate LOCKDOWN independently
8. Can distinguish self from field

**If all 8:** System healthy. Continue.
